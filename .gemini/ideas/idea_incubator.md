# 💡 GSFHub Idea Incubator & Feature Backlog

> **Purpose**: This directory (`.gemini/ideas/`) is the permanent storage for temporary, exploratory, and future feature ideas that are not yet assigned to an active Phase Implementation Plan.

---

## 🌟 Unassigned & Future Ideas Incubator

### 1. 🤖 Discord Bot Integration & Web Export Hub (Post-Phase 6)
* **Concept:** A 1-click **"Export for Discord"** button that generates formatted Discord Markdown tables/embeds ready to paste directly into guild channels (`#guild-crafters`, `#active-orders`, `#guild-needs`).
* **Advanced Concept:** Webhook / JSON export integration for external guild websites.
* **Status:** Deferred from Phase 3 planning; saved for future dedicated integration phase.

### 2. 🎵 Customizable Audio Cues & Sound Themes
* **Concept:** Allow players to select distinct sound effects for different event triggers:
  - 🔔 *Work Order Posted / Claimed*
  - 📬 *Bounty Mailed / Delivered*
  - ⏰ *Alt Cooldown Ready*
  - 💎 *Rare Recipe Drop Detected in Group*
* **Status:** Backlog idea.

### 3. 💬 Guild Chat Specialization Badges & Hover Tooltips
* **Concept:** When a guild member speaks in Guild Chat, hovering over their name in chat displays their GSFHub crafter badge (e.g. `[🧵 Shadoweave Tailor]`, `[⛏️ Miner]`).
* **Status:** Exploratory idea.

### 4. 💾 Base64 Account Profile Export / Import Backup
* **Concept:** Generate a compact Base64 string of all local character settings, wishlists, and alts to easily copy between different computers or backup after fresh game installs.
* **Status:** Backlog idea.

### 5. 👥 Multi-Account & Multi-Client Architecture
* **Concept:** Seamless cross-account alt linking, cooldown alerts, and wishlist sync when a player uses multiple accounts (`WoW1`, `WoW2` or separate Battle.net accounts).
* **Detailed Design:** See [`multi_account_architecture_idea.md`](multi_account_architecture_idea.md).
* **Status:** Incubating for Phase 4 / Phase 5 refinement.

### 6. 👤 Solo / Non-Guild Account Mode ("Virtual Account Hub")
* **Concept:** Allow players without a guild (or playing solo / managing their own alts) to use GSFHub across all characters on their account/realm with a virtual "Account Guild" placeholder.
* **Detailed Design:** See [`solo_account_mode_idea.md`](solo_account_mode_idea.md).
* **Status:** Incubating / Backlog idea.
